# 🎉 [v1.1.0] 릴리즈

🚀 "붕어빵 탐험대"의 두 번째 공식 릴리즈입니다!  
기본적인 기능을 포함하여 정식 배포되었습니다. 🎊

## 📌 주요 기능 (Key Features)
- 📝관리자
	- 커뮤니티 게시글 관리 기능
		- 게시글 등록 시 사진 파일 첨부 가능
		- 게시글 수정 및 삭제 지원
		- 전체 게시글 조회 기능
- 👩사용자
	- 📋 커뮤니티 게시판 기능
		- 전체 게시글 조회
		- 개별 게시글 상세 조회
	- 🎯 커뮤니티 참여 및 소통 기능
		- 주제 추천을 통한 게시글 아이디어 제안
		- 댓글 작성, 조회, 수정 및 삭제 기능 추가
		- 댓글에 대한 좋아요 기능 지원
	- 📊 실시간 커뮤니티 투표 기능
		- WebSocket을 활용한 실시간 투표 현황 조회
	- ⭐ 붕어빵 평점제 기능
		- 붕어빵 별로 유저가 평점을 줄 수 있도록 기능 추가
	- 🏬 가게 등록, 가게 찜하기 기능
		- 붕어빵 가게를 등록하여 다른 사용자들에게 가게 위치를 제공
		- 가게 찜하기 기능 추가

## 🛠 기술 스택 (Tech Stack)
- Java17, SpringBoot, JPA, Jenkins, Mysql, AWS, WebSocket

## 패키지 구조 설명
- 비로그인 사용자가 추가되어 좀 더 사용자 관점으로 패키지를 분리하는 것이 핵심으로 잡았습니다.
- 간략한 패키지 구조에 대해 설명 드립니다.
fish
├── admin(Path : /admin/**)# 관리자용 기능         
│   ├── controller
│   ├── service
│   └── dto
├── member(Path : /member/**)# 로그인 사용자용 기능
│   ├── controller
│   ├── service
│   └── dto
├── guest(Path : /guess/**)# 비로그인 사용자용 기능
│   ├── controller
│   ├── service
│   └── dto
├── common        # 공통 유틸, 설정, 예외 등
├── domain        # 엔티티 + 레포지토리
├── global        # 시큐리티, 인터셉터, 필터 설정 등
