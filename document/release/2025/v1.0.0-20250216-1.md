# 🎉 [v1.0.0] 최초 릴리즈

🚀 "붕어빵 탐험대"의 첫 번째 공식 릴리즈입니다! 
기본적인 기능을 포함하여 정식 배포되었습니다. 🎊

## 📌 주요 기능 (Key Features)
- ✨ 카카오 로그인
- 🔍 붕어빵 유저 정보 조회
- 📝 최초 로그인 사용자 데이터 처리
- 📅 메인 주간 붕어빵 요일 조회
- 🏷 붕어빵 등록
- 📆 붕어빵 캘린더 전체 조회
- 📋 붕어빵 캘린더 상세 조회
- ✏ 붕어빵 캘린더 일지 편집
- 🍞 붕어빵 맛 종류 조회
- 📖 사용자용 붕어빵 도감 조회
- 🔎 사용자용 붕어빵 도감 상세 조회
- 💬 붕어빵 맛 제보
- ✅ 등록 완료 데이터 조회
- 🎭 취향 테스트 MBTI 조회
- 📊 취향 테스트 MBTI 카운트

## 🛠 기술 스택 (Tech Stack)
- Java17, SpringBoot, JPA, Jenkins, Mysql, AWS
